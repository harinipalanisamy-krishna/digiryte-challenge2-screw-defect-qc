# digiryte-challenge2-screw-defect-qc
Anomaly detection system that classifies screws as good or defective using ResNet18 transfer learning, achieving 87% overall accuracy (88% recall on defects). Includes proper hyperparameter tuning via cross-validation, Grad-CAM explainability, and a live Streamlit demo. Built for Digiryte's Round 3 technical challenge.
